# 🎮 Tic-Tac-Toe Game (Two Player & AI Mode)

A responsive, browser-based Tic-Tac-Toe game where you can play with a friend or challenge a basic AI opponent. Built with **HTML**, **CSS**, and **JavaScript**.

---

## 🔧 Features

- 🎲 **Two Game Modes**
  - **Two Player Mode**: Play with a friend on the same device.
  - **Player vs AI**: Compete against a basic AI powered by the Minimax algorithm.

- 🧠 **Smart AI**
  - Unbeatable AI that uses optimal strategy.
  
- 💅 **Stylish UI**
  - Centered game board inside a modern box.
  - Highlights winning cells with a different color.
  - Responsive layout and clean interface.

- 🔁 **Game Controls**
  - Play Again button to restart the match.
  - Back to Mode Selection to choose a different game mode.
